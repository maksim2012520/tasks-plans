# tasks-plans
App for your tasks and plans
## Описание
Приложение для создания и управления задачами (списками дел). Помогает планировать и отслеживать выполненные и невыполненные задачи.

## Особенности
- Простой и понятный интерфейс.
- Быстрая и удобная работа с задачами.
- Синхронизация с базой данных.
